# Briefs — shared facts

Authority: `tasks.md` (scope, files) > `briefs/<ID>.md` (how) > `SPEC.md` (detail) > `design/DESIGN.md` (rules) > `design/css/*` (values) > `design/mockups/*.html` (composition). Planner rulings at the end of `tasks.md` override briefs. Real contradiction → stop and ask.

Shared facts
- Repo `doby-llm/web-dani`, branch `main`, Node 22 (`.nvmrc` = 22), npm. Astro **6.4.8** pinned (do not upgrade: Astro 7 needs Node ≥ 22.23).
- Base path: `/web-dani/` on GitHub Pages; always build URLs with `import.meta.env.BASE_URL` through `src/lib/url.ts` → `url(path)`. Never write `href="/…"` by hand.
- Mockups are static HTML in `design/mockups/<name>.html` (open them in a browser; the class names ARE the implementation contract). Reference screenshots: run `node design/mockups/shoot.mjs <name>` (needs `npm i puppeteer-core` in a scratch dir) or read the PNGs if present in `design/mockups/shots/`.
- Mockup → route mapping: SPEC §3. Mockup links (`home.html`, `contacto.html`) map to routes (`/`, `/contacto/`).
- Copy: `src/data/copy/<page>.json` (generated by T02, after overrides). Microcopy: SPEC §4.3. If a string you need is in neither place, STOP and ask — do not write it.
- Mockup text that differs from the JSON: the JSON wins (mockups were drawn before overrides).
- Icons: `<Icon name="arrow-right" />` (ids in `public/icons.svg`, without the `i-` prefix).
- Images: `src/assets/img/*.png|webp` via `astro:assets` `<Image>` with explicit `widths` and `sizes`; decorative ones get `alt=""`.
- Env flags: `src/lib/env.ts` exports `INDEXABLE`, `PROVISIONAL`, `SHOW_EDITORIAL`, `FORM_ENDPOINT`.
- Screenshots for receipts: `npm run shots -- /ruta/ /otra/` → `shots/<slug>-{desk,mob}-NN.png` (script from T01).
- Pi resources: run at most one `astro build` at a time (`flock /tmp/web-dani-build.lock npm run build`).
- No secrets exist in this project. Never add analytics, external fonts, CDNs or trackers.
