# T01 — Astro scaffold, design system port, CI/Pages
> v4 brief (2026-11-17). Supersedes the v2 version; DESIGN.md v4 + mockups are the visual authority. Rulings R16–R21 in tasks.md apply.

## Goal
Create the empty Astro project with the design system already in place, a reproducible build, Pages deploy via Actions and a screenshot script, so every later task only adds pages/components.

## Read first
SPEC §2 (DEC-02, DEC-03, DEC-08), §8; DESIGN.md §3–§4; `design/css/*.css`, `design/js/site.js`, `design/fonts/`, `design/icons.svg`, `design/img/`, `design/mockups/shoot.mjs`.

## Steps
1. `npm init -y`; set `"type": "module"`, `"private": true`, `"engines": {"node": ">=22.12 <23"}`. Install exact: `astro@6.4.8`, `yaml@2`. `.nvmrc` = `22`.
2. `astro.config.mjs`:
   ```js
   import { defineConfig } from 'astro/config';
   export default defineConfig({
     site: process.env.SITE_URL ?? 'https://doby-llm.github.io',
     base: process.env.BASE_PATH ?? '/web-dani/',
     trailingSlash: 'always',
     build: { format: 'directory', inlineStylesheets: 'auto' },
     prefetch: { prefetchAll: false, defaultStrategy: 'hover' },
     compressHTML: true,
   });
   ```
3. `.env.example` with the 6 variables of SPEC §8 and their prototype values. `src/env.d.ts` typing them.
4. Copy CSS: `design/css/{tokens,base,components}.css` → `src/styles/` byte-for-byte. Create `src/styles/global.css` = `@import "./tokens.css"; @import "./base.css"; @import "./components.css";`. Fonts live in `src/assets/fonts/`, so in `tokens.css` change only the three font URLs to `url("../assets/fonts/fraunces-web.woff2")`, `url("../assets/fonts/fraunces-italic-web.woff2")` and `url("../assets/fonts/public-sans-web.woff2")`; Vite then hashes them and applies the base path. Only those three lines may differ from `design/css` (row M2). For `<link rel="preload">` later, T03 imports them as `import serif from '../assets/fonts/fraunces-web.woff2?url'`.
5. Copy `design/fonts/{fraunces-web,fraunces-italic-web,public-sans-web}.woff2` → `src/assets/fonts/`; `design/fonts/*.ttf` (4 files) → `src/assets/og-fonts/` (used by T10). Do not copy `design/fonts/sources/`. Copy `design/icons.svg` → `public/icons.svg`. Copy `design/img/{avocado,grapefruit,lemon-a,lemon-b,lemon-c}.png` → `src/assets/img/`, and `design/img/portrait-placeholder.webp` three times as `src/assets/img/{portrait,working,avatar}.webp` (R15).
6. Copy `design/js/site.js` → `src/scripts/site.js` unchanged.
7. Placeholder `src/pages/index.astro` importing `../styles/global.css` with an `<h1>Hola</h1>`.
8. `scripts/shots.mjs`: adapt `design/mockups/shoot.mjs` to take routes (`/`, `/programas/`) against `astro preview` on `http://localhost:4321/web-dani/`, writing `shots/<slug>-{desk,mob}-NN.png`. Add devDependency `puppeteer-core@24` and script `"shots": "node scripts/shots.mjs"`; executable path from `CHROMIUM_PATH` env, default `/usr/bin/chromium`.
9. Scripts: `dev`, `build`, `preview`, `check` (= `npm run check:copy` placeholder `echo ok` for now; T11 extends).
10. `.github/workflows/deploy.yml`: on push to `main` + workflow_dispatch; jobs `build` (checkout, setup-node from `.nvmrc`, `npm ci`, `npm run build` with env from repo vars or the defaults, `actions/upload-pages-artifact@v3` path `dist`) and `deploy` (`actions/deploy-pages@v4`, permissions pages:write, id-token:write, environment github-pages). Concurrency group `pages`.
11. `.gitignore`: node_modules, dist, dist-indexable, .astro, shots, .env, test-results, playwright-report, .lhci.
