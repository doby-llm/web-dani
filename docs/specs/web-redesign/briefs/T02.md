# T02 — Copy pipeline

## Goal
Turn the verbatim prototype copy (`content-src/copydeck/*.yaml`) plus the approved client rewrites (`content-src/overrides.yaml`) into JSON the pages import, with a check that fails on drift or on an override that no longer matches. This is what guarantees "only the text of the old site" (Manu's requirement) while removing internal/dev notes.

## Read first
SPEC §4.1, §4.2, DEC-05/06/07; `content-src/overrides.yaml` (header comments explain the format); two copy files: `home.yaml`, `contacto.yaml`.

## Steps
1. `scripts/build-copy.mjs` (Node, uses `yaml`):
   - For each `content-src/copydeck/<page>.yaml` (skip `README.md`), load it as an object. Page key = file name without extension (`home`, `_shared`, …).
   - Apply overrides for that page key in file order: walk every string value in the object (deep); for each override, replace **every exact occurrence** of `find` inside each string with `replace` (`String.prototype.replaceAll`). If the override has `where` (a dotted/indexed path like `header.nav_cta` or `form.fields[2].label`), apply it ONLY at that path. Count matches; if an override matched 0 times → collect an error.
   - After replacing: remove keys `eyebrow`, `kicker`, `number`, `stamp`, `badge`, `featured`, `recommended`, `scope`, `noscript`, `old_path`; remove list items and fields that became the empty string `""`; remove `ctas` entries that became empty.
   - Attach notes: for every `disclaimers` array, convert each string to `{ "text": s, "kind": k }` where `k` comes from `notes_kind` in overrides.yaml (exact match after overrides; default `"provisional"`). Also convert `form.notes`.
   - Write `src/data/copy/<page>.json` (2-space indent, keys in source order, trailing newline). `_shared.yaml` → `shared.json`.
   - Exit 1 listing every zero-match override.
2. `--check` flag: build into memory, compare with files on disk, exit 1 with the list of differing files.
3. package.json scripts: `"copy": "node scripts/build-copy.mjs"`, `"check:copy": "node scripts/build-copy.mjs --check"`. Make `check` run `check:copy`.
4. Run `npm run copy` and commit the JSON.
5. Add a CI step (in the build job, before `npm run build`): `npm run check:copy`.

## Tests
- `npm run copy` exit 0, 16 JSON files.
- Mutation check (do not commit): change one `find` in overrides to a non-existing string → `npm run copy` exits 1 naming it. Revert.
- `grep -l "preventDefault\|captación\|placeholder honesto\|documentada" src/data/copy/*.json` → empty.
- `grep -c "180 €" src/data/copy/home.json` ≥ 1 (facts preserved).
