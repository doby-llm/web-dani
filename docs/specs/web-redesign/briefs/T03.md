# T03 — Layout shell, shared components, 404
> v4 brief (2026-11-17). Supersedes the v2 version; DESIGN.md v4 + mockups are the visual authority. Rulings R16–R21 in tasks.md apply.

## Goal
Build the one layout every page uses (notice bar, header with services disclosure, mobile sheet, action bar, breadcrumb, footer) plus the small shared components, exactly as the mockups `_header.html`, `_footer.html`, `estados-nav.html`. After this task, a page is just `<BaseLayout …>` + sections.

## Read first
SPEC §3, §4.2, §4.3, §6, §7, §8; DESIGN.md §6–§7; `design/mockups/src/_header.html`, `_footer.html`, `estados-nav.html`, `404.html`; `src/scripts/site.js` (behaviour is already written — your markup must match its selectors: `.site-header`, `#menu-sheet`, `[aria-controls="menu-sheet"]`, `[data-close-sheet]`, `.nav-menu`, `.action-bar`, `[data-action-bar-trigger]`, `[data-hide-action-bar]`, `[data-year]`).

## Steps
1. `src/lib/env.ts`:
   ```ts
   const flag = (v: string | undefined, d: boolean) => v === undefined || v === '' ? d : v === 'true';
   export const INDEXABLE = flag(import.meta.env.PUBLIC_INDEXABLE, false);
   export const PROVISIONAL = flag(import.meta.env.PUBLIC_PROVISIONAL, true);
   export const SHOW_EDITORIAL = flag(import.meta.env.PUBLIC_SHOW_EDITORIAL, true);
   export const FORM_ENDPOINT = import.meta.env.PUBLIC_FORM_ENDPOINT ?? '';
   ```
2. `src/lib/url.ts`: `export const url = (p = '') => (import.meta.env.BASE_URL.replace(/\/$/, '') + '/' + p.replace(/^\//, '')).replace(/\/?$/, p.includes('.') || p.includes('?') || p.includes('#') ? '' : '/');` plus unit-like self-check in a comment: `url('')→'/web-dani/'`, `url('programas')→'/web-dani/programas/'`, `url('icons.svg')→'/web-dani/icons.svg'`, `url('contacto/?objetivo=x')` keeps the query.
3. `src/lib/nav.ts`: single source for navigation:
   ```ts
   export const services = [
     { slug: 'perdida-de-peso', path: 'perdida-de-peso/', title: 'Pérdida de peso', icon: 'scale', svc: 'weight' },
     { slug: 'medico', path: 'perdida-de-peso/tratamiento-medico/', title: 'Pérdida de peso con tratamiento médico', short: 'Tratamiento médico', icon: 'stethoscope', svc: 'medical' },
     { slug: 'deportiva', path: 'nutricion-deportiva/', title: 'Nutrición deportiva', icon: 'dumbbell', svc: 'sport' },
     { slug: 'clinica', path: 'nutricion-clinica/', title: 'Nutrición clínica', icon: 'heart-pulse', svc: 'clinic' },
   ];
   export const primary = [ { key: 'como', path: 'como-funciona/', label: 'Cómo funciona' }, { key: 'programas', path: 'programas/', label: 'Programas' }, { key: 'sobre', path: 'sobre-mi/', label: 'Sobre mí' }, { key: 'blog', path: 'blog/', label: 'Blog' } ];
   ```
   The services-menu descriptions come from `home.json` goals items text (pérdida de peso, deportiva, clínica) and, for médico, the sentence "No es una solución aislada: se integra con seguimiento nutricional y de hábitos." (from `home.json` medical section paragraph; take the substring after the first sentence). Read them in the component, do not hard-code.
4. Components (each a thin wrapper of the catalogue classes; props typed):
   - `Icon.astro` `{ name: string; class?: string; label?: string }` → `<svg class:list={['icon', cls]} aria-hidden={label ? undefined : 'true'} role={label ? 'img' : undefined} aria-label={label}><use href={url('icons.svg') + '#i-' + name}/></svg>`.
   - `Button.astro` `{ href; variant: 'primary'|'secondary'; block?; arrow?: boolean }` (arrow default true for primary).
   - `Note.astro` `{ note: { text: string; kind: 'legal'|'provisional'|'editorial' } | string; boxed?: boolean; icon?: string }`: string → kind provisional. Render `<p class="note">` with `info` icon (or `icon`) only if `kind==='legal' || (kind==='provisional' && PROVISIONAL) || (kind==='editorial' && SHOW_EDITORIAL)`.
   - `Still.astro` `{ objects: { src: ImageMetadata; w: string; top?: string; left?: string; right?: string; bottom?: string; rotate: number }[]` (CSS lengths/percentages copied from the mockup inline styles; exactly two of top/bottom/left/right per object; settle?: boolean }` → `<div class="still" class:list={{'still--settle': settle}} aria-hidden="true">` with `<Image class="still__obj" src alt="" widths={[240,480]} sizes="(max-width: 899px) 40vw, 20vw" style=…>`; max 3 objects (throw if more).
   - `Fiche.astro` `{ title: string; icon: string; rows: { dt: string; dd: string; href?: string }[] }` → the `aside.fiche` of `servicio.html` (`aria-label` = microcopy `fiche.aria`, icon in `span.icon-badge`).
   - `src/lib/text.ts`: `accent(text: string, n: number): string` returns HTML-escaped text with the last `n` words wrapped in `<em>` (n = 0 → escaped text). Used with `set:html` on h1/h2 (R19).
   - `Breadcrumb.astro` `{ items: { label; href? }[] }` (first item always Inicio → `url('')`; last item `aria-current="page"`, no link). JSON-LD is added by T10, not here.
   - `Header.astro` `{ current?: 'como'|'programas'|'sobre'|'blog'|'servicios' }`: markup = `_header.html` with links from nav.ts; when `current==='servicios'` add the attribute `data-current="true"` to the services button and nothing else (no underline; `aria-current` is not valid on a disclosure button). Nav CTA label "Contacto" (shared.json `header.nav_cta` after overrides).
   - `ServicesMenu.astro` used inside Header: button `aria-expanded="false" aria-controls="services-panel"` + panel `hidden`.
   - `MenuSheet.astro`: markup of the `.sheet` in `_footer.html`; `inert` attribute present by default; CTA label = shared.json `floating.mobile_contact_bar` ("Cuéntame tu objetivo"); also lists FAQ.
   - `ActionBar.astro` `{ hidden?: boolean }`: one primary button "Cuéntame tu objetivo" → `url('contacto/')`; render nothing if `hidden`.
   - `Footer.astro`: `_footer.html` footer part (`.site-footer` on `--footer`, `.brand__mark` inverted, tagline = shared.json footer text). Columns/labels from shared.json; add "Tratamiento médico" under Servicios (microcopy nav.medical). Bottom-right text = site notice only if `PROVISIONAL`. Year `<span data-year>` with build-time year as fallback.
5. `src/layouts/BaseLayout.astro` props: `{ title: string; description: string; ogSlug: string; current?: 'como'|'programas'|'sobre'|'blog'|'servicios'; hideActionBar?: boolean; article?: {published?: string} }`. Structure:
   ```astro
   <html lang="es"><head>
     <meta charset="utf-8"><meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">
     <title>{title}</title><meta name="description" content={description}>
     <link rel="preload" href={serif} as="font" type="font/woff2" crossorigin>
     <link rel="preload" href={sans} as="font" type="font/woff2" crossorigin>
     <slot name="head" />   <!-- T10 inserts <Seo/> here and replaces title/description -->
   </head><body>
     <a class="skip-link" href="#main">Saltar al contenido</a>
     {PROVISIONAL && <p class="site-notice">{shared.site_notice}</p>}
     <Header …/>
     <slot />   <!-- pages render <main id="main"> themselves -->
     <Footer/><ActionBar hidden={hideActionBar}/><MenuSheet/>
     <script src="../scripts/site.js"></script>
   </body></html>
   ```
   Import `../styles/global.css` in the frontmatter. Breadcrumb is NOT a layout prop: each page places `<Breadcrumb>` inside its hero, as in the mockups.
6. `src/pages/404.astro`: mockup `404.html` (bg-sport hero, 2-object Still as in the mockup), copy = microcopy `404.h1`, `404.lead`, buttons `404.cta` → `url('')` and nav CTA label → `url('contacto/')`; `hideActionBar`.
7. Update the placeholder `index.astro` to use BaseLayout (`<main id="main"><h1>Hola</h1></main>`) — T04 replaces it.
