# T05 — Services index and the three service pages

> v4 brief (2026-11-17). Supersedes the v2 version; DESIGN.md v4 + mockups are the visual authority.

## Goal
Build `/servicios/` (service directory rows, "Cómo elegir") and the three service pages `/perdida-de-peso/`, `/nutricion-deportiva/`, `/nutricion-clinica/` in the v4 composition of `servicio.body.html` (SPEC §3, T-SERVICE).
