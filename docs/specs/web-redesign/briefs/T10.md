# T10 — SEO, social cards, icons
> v4 brief (2026-11-17). Supersedes the v2 version; DESIGN.md v4 + mockups are the visual authority. Rulings R16–R21 in tasks.md apply.

## Goal
Make every page correct for search engines and attractive when shared (WhatsApp, Instagram DM, Telegram, LinkedIn, X): titles, descriptions, canonical, robots per environment, generated PNG social cards in the site's visual world, structured data, sitemap and favicon set. The old site used an SVG card, which WhatsApp does not render; this task fixes that.

## Read first
SPEC §2 (DEC-08, DEC-10), §4.4, §5, §8; DESIGN.md §3–§4; `src/layouts/BaseLayout.astro` (T03); `src/assets/og-fonts/*.ttf`; `src/assets/img/*.png`.

## Steps
0. Colours: read the hex values from the `PALETTE:BEGIN … PALETTE:END` block of `src/styles/tokens.css` at build time (parse `--name: #hex;` lines) and use them in satori, icons and manifest. Never hard-code hex values: the palette may change (DEC-12).
1. Install exact: `@astrojs/sitemap@3.7.5`, `satori@0.63.2`, `@resvg/resvg-js@2.6.2`.
2. `src/data/seo.json`: one entry per route key (`home`, `servicios`, `perdida-de-peso`, `medico`, `nutricion-deportiva`, `nutricion-clinica`, `como-funciona`, `programas`, `sobre-mi`, `preguntas-frecuentes`, `blog`, `contacto`, `aviso-legal`, `privacidad`, `cookies`, `404`) with `{ path, title, description, ogTitle, ogTag, ogImage: "home"|…, ogObject: "avocado"|"grapefruit"|"lemon-a"|"lemon-b"|"lemon-c"|null }`. title/description = SPEC §4.4 exactly. ogTitle = the page H1 from the copy JSON (after overrides). ogTag: home "Nutrición online", service pages their service title, médico "Tratamiento médico", others the nav label. `ogObject: null` for medico, programas, preguntas-frecuentes, aviso-legal, privacidad, cookies and all articles (R20). Others: home avocado, servicios avocado, perdida-de-peso grapefruit, nutricion-deportiva lemon-c, nutricion-clinica avocado, como-funciona lemon-a, sobre-mi lemon-a, blog lemon-b, contacto lemon-a, 404 lemon-b. Add `ogAccent: number` = the n used for the page h1 accent (R19; 0 if none).
3. `src/lib/seo.ts`: `absolute(path)` = `new URL(url(path), import.meta.env.SITE).href`; `jsonLd(page)` builds `@graph`:
   - `WebSite` {@id site#website, url, name "Daniel Clemente · Nutricionista", inLanguage "es-ES"}
   - `Person` {@id site#daniel, name "Daniel Clemente", jobTitle "Nutricionista", alumniOf [{CollegeOrUniversity "Universidad Europea de Madrid"}, {CollegeOrUniversity "Universidad Católica de Murcia"}], knowsAbout ["Pérdida de peso","Nutrición deportiva","Nutrición clínica","Composición corporal"], url = sobre-mi absolute}
   - `ProfessionalService` {@id site#service, name "Daniel Clemente · Nutricionista", url home, areaServed {Country "ES"}, founder {@id site#daniel}, serviceType ["Nutrición online"], availableLanguage "es"} — no address/phone/priceRange.
   - plus per page: `BreadcrumbList` (inner pages, same items as the visible breadcrumb), `FAQPage` (FAQ: question/answer from `preguntas-frecuentes.json`), `BlogPosting` (articles: headline, datePublished, author @id daniel, image og).
   - Never emit `Offer`, `MedicalBusiness`, `Physician`, `Drug`.
   NOTE on UEM/UCAM full names: the copy says only "UEM" and "UCAM"; the expansions above are the institutions' official names (planner-verified) and appear only in JSON-LD, never in visible copy.
4. `src/components/Seo.astro` props `{ key: string; type?: 'website'|'article'; article?: {published: string; modified?: string}; titleOverride?; descriptionOverride? }` renders: `<title>`, description, canonical, robots (`INDEXABLE ? 'index,follow,max-image-preview:large' : 'noindex,nofollow'`), theme-color = `--brand` value, `<link rel="icon" href=favicon.svg type="image/svg+xml">`, `<link rel="icon" href=favicon-32.png sizes="32x32">`, apple-touch-icon, manifest, OG (`og:type, og:site_name, og:locale es_ES, og:title (= ogTitle), og:description, og:url, og:image, og:image:secure_url, og:image:type image/png, og:image:width 1200, og:image:height 630, og:image:alt "<ogTitle> — Daniel Clemente, nutricionista"`), Twitter (`summary_large_image`, title, description, image, image:alt), JSON-LD `<script type="application/ld+json" set:html={JSON.stringify(graph)}>`.
5. BaseLayout: remove its own `<title>`/description; render `<Seo key={ogSlug} …/>` in head. Add prop passthrough for article.
6. `src/pages/og/[slug].png.ts`: `getStaticPaths` from seo.json keys + published blog posts. Render with satori (1200×630) this layout, then `new Resvg(svg).render().asPng()`:
   - background `--brand` value; padding 72 px; a soft disc of `--brand-tint` value at 18 % opacity, 560 px, centred on the food object (behind it);
   - top-left brand line: rounded-square mark 56 px (`--paper` fill, "DC" Fraunces 560 24 px in `--brand`) + "Daniel Clemente" Fraunces 560 34 px paper + "Nutricionista" Public Sans 500 24 px `--brand-soft` value;
   - title: Fraunces 560, 72 px (62 px if > 48 chars, 54 px if > 70), line-height 1.05, letter-spacing −1 px, colour `--paper` value, max width 760 px, bottom-left; if `ogAccent` > 0 the last `ogAccent` words are Fraunces italic 450 in `--sun` value;
   - pill with `ogTag`: `--sun` fill, radius 999, Public Sans 700 24 px ink, padding 10/22, above the title (left aligned, 28 px gap);
   - food object (if any): PNG data URI from `src/assets/og-objects/<name>.png`, width 360 px, right 40, top 120, rotate −12°. No shadow (satori has no blur filter).
   - Fonts: read `src/assets/og-fonts/fraunces-og-560.ttf`, `fraunces-og-italic-450.ttf` (style italic), `public-sans-og-500.ttf`, `public-sans-og-700.ttf` with `fs.readFile` (resolved from `process.cwd()`).
   - Output must be ≤ 300 KB; that is why objects are pre-resized to 400 px by `scripts/make-icons.mjs` (step 7).
7. `scripts/make-icons.mjs` (run once, outputs committed) using `@resvg/resvg-js`:
   - `public/favicon.svg`: 64×64, rounded square r=14 fill `--brand` value, "DC" in paper (generate the glyph paths once with satori from `fraunces-og-560.ttf`, 30 px, centred, and inline the resulting `<path>`s), small dot `--sun` value r=4 at (52,12).
   - Rasterize to `favicon-32.png`, `apple-touch-icon.png` (180, no transparency, brand bg), `icon-512.png`.
   - `src/assets/og-objects/<name>.png` 400 px wide from `src/assets/img/<name>.png` using `sharp` (already installed as an Astro dependency; import it, do not add it to package.json).
   - `public/site.webmanifest`: `{ "name": "Daniel Clemente · Nutricionista", "short_name": "D. Clemente", "lang": "es", "start_url": "./", "display": "browser", "background_color": "<--paper>", "theme_color": "<--brand>", "icons": [{"src":"icon-512.png","sizes":"512x512","type":"image/png"},{"src":"apple-touch-icon.png","sizes":"180x180","type":"image/png"}] }`.
8. `astro.config.mjs`: add `sitemap({ filter: (p) => !p.includes('/og/') && !p.endsWith('/404/') })`.
9. `src/pages/robots.txt.ts`: `INDEXABLE` → `User-agent: *\nAllow: /\nSitemap: <absolute sitemap-index.xml>` else `User-agent: *\nDisallow: /`.
