- **Class:** bug
- **Owning files:** `src/styles/components.css` (frozen, T01) for `.brand`, `.site-footer` links, `.breadcrumb a`, `.link-arrow`; `src/components/Header.astro`, `Footer.astro`, `Breadcrumb.astro` (markup only).
- **Fix:** Give `.brand`, footer links, breadcrumb links and link-arrows a 44 px hit area (padding or `min-height`) without changing the visible layout. Needs a planner ruling because components.css is frozen. Inline prose links need a ruling (WCAG 2.5.8 inline exception vs SPEC §7 "≥ 44").
